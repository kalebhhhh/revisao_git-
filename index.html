Principais Atalhos do Visual Studio Code

  • Ctrl + P → Abrir arquivo rapidamente
  • Ctrl + Shift + P → Paleta de Comandos
  • Ctrl + S → Salvar arquivo
  • Ctrl + N → Novo arquivo
  • Ctrl + / → Comentar ou descomentar linha
  • Ctrl + Shift + F → Pesquisar em todo o projeto
  • Ctrl + H → Localizar e substituir
  • Ctrl + ` → Abrir terminal integrado
  • Alt + ↑ / ↓ → Mover linha para cima ou para baixo
  • Shift + Alt + ↓ → Duplicar linha
